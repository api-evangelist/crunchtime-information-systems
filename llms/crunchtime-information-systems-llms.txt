## API Reference

User Management:
- getAllApplicationUsers — Retrieve Application Users with limited or detailed data via userIdForDetails
- getApplicationUsersByPage — Paginated retrieval with optional details
- saveApplicationUser — Create or update application users
- validate-user — Validate site access credentials

Budget & Financial:
- getAllBudget / getBudgetByPage / saveBudget — Budget records by location and post date
- getAllGeneralLedgersV1 / saveGeneralLedgerV1 — General ledger entries

Categories & Products:
- getAllCategories / getCategoriesByPage / saveCategory
- getAllCompanyProductsEnhancedV1 / getCompanyProductsEnhancedByPage / saveCompanyProductEnhancedV1

Menu Mix & Sales:
- GetAllCheckMenuMixRecordsV1 / getCheckMenuMixRecordsByPage / saveCheckMenuMixRecordsV1
- getAllSalesMix / getSalesMixByPage / saveSalesMix

Commissary & Orders:
- getAllCommissaryOrders / getCommissaryOrdersByPage
- getAllCustomerOrderEnhanced / getCustomerOrderEnhancedByPage / saveCustomerOrderEnhanced

Inventory Management:
- getAllInventoryAdjustments / getInventoryAdjustmentsByPage / saveInventoryAdjustments
- getAllInventoryValueAdjustments / getInventoryValueAdjustmentsByPage / saveInventoryValueAdjustments
- getAllPhysicalInventoryStandards / getPhysicalInventoryStandardsByPage / savePhysicalInventoryStandards
- getCurrentInventoryByPage
- getAllProjectedConsumption / getProjectedConsumptionByPage / saveProjectedConsumption

Daily Prep Management:
- getAllDailyPreps / getDailyPrepsByPage / saveDailyPreps (beta)

Receipts & Confirmations:
- getAllConfirmReceiptsStandard / getConfirmReceiptsStandardByPage / saveConfirmReceiptStandard

Currency & Pricing:
- getAllCurrencyRatio / getCurrencyRatioByPage / saveCurrencyRatio
- getAllLocationProductPricing / getLocationProductPricingByPage / saveLocationProductPricing

Customers:
- getAllCustomers / getCustomersByPage / saveCustomers

Employees & Labor:
- getEmployeeV1 / getEmployeeNumbersV1 / getEmployeesByPageV1 / saveEmployeeV1
- getSchedulesV1
- getAllTimeClockEnhanced / getTimeClockEnhancedByPage / saveTimeClockEnhanced
- getAllSupplementalWagesV1 / getSupplementalWagesByPage / saveSupplementalWages

Locations:
- getAllLocationsV1 / getLocationsByPageV1 / saveLocationV1

Hierarchies:
- getHierarchiesV2 / getHierarchyDetailsV2 / saveHierarchyV2

Nutrition:
- getAllNutritions / getNutritionsByPage / saveNutritions

Package Types:
- getAllPackageTypesV2 / getPackageTypesByPageV2 / savePackageTypesV2

PBI (Performance Based Incentives):
- getAllPbisV2 / getAllPbisByPageV2 / savePbiV2

Recipes:
- getAllRecipesEnhancedV2 / getRecipesEnhancedByPageV2 / saveRecipesV2
- getAllRecipeLocations / getRecipeLocationsByPage / saveRecipeLocation

Sales Forecasting:
- get15MinutesSalesForecast / get15MinutesSalesForecastByPage / save15MinutesSalesForecast
- getDailySalesForecast / getDailySalesForecastByPage / saveDailySalesForecast
- getHourlySalesForecast / getHourlySalesForecastByPage / saveHourlySalesForecast

Purchase Orders:
- getAllPurchaseOrders / getPurchaseOrdersByPage / savePurchaseOrders
- saveElectronicInvoice (beta, Customer Restricted Access)

Scheduled Exports:
- downloadScheduledExport / getAllScheduledExportsV1 / markScheduledExportV1

Storage Locations:
- getAllStorageLocations / getStorageLocationsByPage / saveStorageLocations

Vendors:
- getAllVendorsV1 / saveVendor
- getAllVendorLocation / getVendorLocationByPage / saveVendorLocation
- getAllVendorPayment / getVendorPaymentByPage / saveVendorPayment
- getAllVendorProductPricing / getVendorProductPricingByPage

UDA (User Defined Attributes):
- getUdaLocations / getUdaVendors
